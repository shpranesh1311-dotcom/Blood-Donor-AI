About This AI System

What this system does

This is a B.Tech Artificial Intelligence & Data Science student project. During a blood emergency, a hospital or patient usually already knows the required blood group - the harder problem is knowing which eligible donors are actually likely to be available and respond quickly. This system combines blood-group compatibility, donor eligibility rules, approximate distance, historical donor behaviour, and request urgency into a single predicted response probability and an intelligent ranking of the best candidates to contact first.

How the AI prediction works

A machine learning model (Logistic Regression, Random Forest, and XGBoost were compared; the best performer was selected by ROC-AUC and then probability-calibrated) is trained on synthetic historical donor-response data. It outputs the probability that a given donor will respond to a given emergency request, based on features such as blood-group compatibility, distance, previous response rate, average response time, current availability, urgency, and time-of-day/day-of-week patterns.

How ranking works

The raw ML probability is one input into a configurable ranking formula (see app/services/ranking_config.json) that also considers distance, historical response rate, current availability, expected response speed, and how well a donor's speed profile matches the request's urgency. Weights are transparent and can be retuned without changing code.

What this system does NOT do
  • It does not provide medical advice.
  • It does not make final donor eligibility decisions - see the eligibility disclaimer on every match result.
  • It does not replace doctors, hospitals, or blood banks.
  • It cannot guarantee that any donor will actually donate - predictions are probabilistic estimates for prioritisation only.
  • It does not use, store, or display any real person's private data - all donor records are synthetically generated for demonstration.
Technology Stack
  • FastAPI + Uvicorn (backend/API)
  • SQLAlchemy + SQLite (default) / PostgreSQL (optional)
  • Scikit-learn + XGBoost + Joblib (ML)
  • Bootstrap 5 + Chart.js + Leaflet/OpenStreetMap (frontend)
Ethical & Privacy Notes

All donor names, locations, and histories in this demo are fictional and generated by a reproducible script (ml/generate_dataset.py). A real deployment would require clinical validation, strict privacy controls, security review, informed consent, and integration with authorized healthcare systems and blood banks.
